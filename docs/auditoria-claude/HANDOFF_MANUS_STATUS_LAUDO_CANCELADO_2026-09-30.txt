--------------------------------------------------------------------------------
3. A CORREÇÃO
--------------------------------------------------------------------------------

Arquivo: server/db.ts, função getStudyReportStatusPresentation()

Único ramo alterado — quando TODOS os documentos de um estudo estão
cancelados (`total > 0 && cancelled === total`):

  ANTES:
    { label: "Laudo cancelado",
      detail: "Assinatura cancelada — nova laudagem necessária" }

  DEPOIS:
    { label: "Pendente", detail: null }

O ramo de CANCELAMENTO PARCIAL (`cancelled > 0` mas nem todos) NÃO foi
tocado — continua mostrando "Cancelamento parcial" com o detalhe de
quantos documentos foram cancelados, porque esse caso é diferente (há
pelo menos um documento válido no mesmo estudo) e o Alessandro não
pediu para mudar esse.

Nenhum dado é apagado ou alterado no banco — o documento continua com
`status = 'cancelled'` e o audit_log continua registrando quem
cancelou e quando. Só a apresentação na worklist muda.
