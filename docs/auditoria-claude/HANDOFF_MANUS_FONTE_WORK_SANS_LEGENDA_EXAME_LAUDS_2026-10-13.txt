1. CONTEXTO / PEDIDO ORIGINAL

O Alessandro notou que a fonte usada no nome do exame/legenda na listagem
PACS parecia "pobre", como se nunca tivesse sido trabalhada.

Causa raiz confirmada em código: o sistema inteiro, fora do módulo
Financeiro, nunca teve nenhuma fonte customizada definida em CSS. O
Tailwind (v4, via @theme default em node_modules/tailwindcss/theme.css)
usa como font-sans o stack padrão `ui-sans-serif, system-ui, sans-serif,
...`, então o navegador renderiza com a fonte padrão do sistema
operacional de quem está vendo a tela (Segoe UI no Windows, San Francisco
no Mac, etc.) — daí o visual genérico. Só o módulo /financeiro/* foge
disso, porque já carrega Manrope e Sora via Google Fonts em
client/index.html.

2. PROCESSO DE ESCOLHA (com o Alessandro, antes de codar)

- Pergunta direta sobre escopo: ele confirmou que o aviso deveria valer
  SÓ para o texto do nome do exame (não o sistema inteiro).
- Gerados 5 mockups autocontidos (HTML com as fontes reais embutidas em
  base64, via pacotes @fontsource baixados do npm neste sandbox, já que
  fonts.googleapis.com está bloqueado aqui mas funciona normalmente na
  VM): Manrope, Inter, IBM Plex Sans, Work Sans, Poppins.
- A pedido dele, 4 dessas opções também foram reproduzidas como páginas
  inteiras (cabeçalho, filtros, tabela completa), replicando um
  screenshot real que ele enviou da tela de produção, para comparação
  lado a lado com o visual atual.
- Ele escolheu Work Sans.

3. IMPLEMENTAÇÃO

a) client/index.html — a tag <link> de Google Fonts do módulo Financeiro
   foi reaproveitada (mesmo host/preconnect, sem duplicar), adicionando
   Work+Sans:wght@400;500;600 à mesma URL:

     https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&family=Sora:wght@500;600;700&family=Work+Sans:wght@400;500;600&display=swap

   Nenhum preconnect novo foi necessário (os dois já existiam).

b) client/src/index.css — nova classe utilitária isolada, dentro de
   @layer base, que NUNCA é aplicada ao body/seletor global:

     .exam-legend-font {
       font-family: 'Work Sans', ui-sans-serif, system-ui, sans-serif;
     }

c) client/src/pages/PacsQueryPage.tsx — a classe é aplicada SOMENTE no
   `<span>` de texto dentro do componente ExamName (único lugar do
   arquivo onde esse componente é usado: a coluna "Exame" da tabela
   desktop). O ícone/badge de modalidade ao lado não foi alterado — só o
   texto do nome do exame.
